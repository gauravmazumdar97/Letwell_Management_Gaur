# Product notes (Week 1)

## Comparable products reviewed (lightweight)

- **Airbnb** - property-led browsing, price unit clarity, photo-first cards
- **Rightmove / SpareRoom** - UK location filters and rent framing
- **Stripe Dashboard** - operational tables, status hierarchy, invoice clarity
- **Apple marketing pages** - typography, spacing, restrained colour

## Primary journeys (draft)

1. Visitor searches approved homes, opens detail, signs in or registers.
2. Tenant requests a booking (Week 2); manager approves; rental + invoices appear.
3. Tenant pays an invoice via Stripe test Checkout (Week 3); earnings update for the manager.
4. Tenant raises maintenance on an active rental; admin assigns a worker (Week 4).

## Public content principles

- Letwell brand is the hero signal on the homepage.
- Show price with an explicit unit (`pcm`, `per night`, `per day`, `per event`).
- Empty search states explain that draft/suspended homes are excluded.
- Every primary CTA either works or states the milestone when it will.
